## 一、服务内容 {#service}

1. Yozi 是面向学生的 AI 学习教练：
   - 通过对话为你建立学习档案；
   - 按你已保存的学习记录安排每日训练与复习；
   - 用知识卡、练习卡、写作带练卡和小结卡教学；
   - 汇总薄弱点、个人句式与搭配库及目标进度。
2. 当前提供考研英语写作带练，覆盖英语一、英语二的应用文与大作文，包括固定搭配、翻译短句、长难句和逐段带写。你也可以上传自己的资料，围绕资料学习。其他科目上线时，会在服务页面说明。
3. 使用端：
   - 桌面 App 和手机 App 是主要使用端。开启同步后，学习记录可以在设备之间同步。
   - 官网目前提供 App 下载和产品说明；注册登录和只读查看本人已同步的学习进度将陆续开放。
   - 各端支持的系统版本以下载页面为准。
4. 部分功能（如本机学习、查看历史记录）无需登录；云同步需要登录。

1. 注册时，请提供真实有效的邮箱，并按提示完成验证。一个账户只限一名自然人使用。
2. 请妥善保管账户密码和 API 密钥，不得出借、转让或出售账户。**因你保管不善或主动泄露造成的损失，由你自行承担。** 发现账户被盗用，请立即修改密码并联系我们。
3. 不得冒用他人身份注册，不得未经授权访问他人账户或学习记录。
4. 如你违反本协议第四条，我们可以视情节采取警告、限制功能、暂停或终止账户等措施，并依法保存记录、向主管部门报告。
5. 你可以按《隐私政策》第七条申请注销账户，冷静期为7天。注销后，账户和云端数据将被删除或匿名化，不能恢复。

## 三、AI 连接与第三方模型服务 {#models}

1. 本服务的 AI 功能默认使用你自行接入的模型服务。你需要自己在服务商处注册账户、获取 API 密钥并支付费用，**并遵守该服务商的服务条款。服务商的收费、额度、可用型号、服务中断，以及它如何处理你的内容，由该服务商负责。**
2. 我们只按你的指令，把完成当前任务所需的内容转发给你选择的服务商，并为每次调用设定次数、时长和费用上限。
3. 可用型号以服务商实时返回的为准。当前型号不可用时，我们会提示你切换，不会擅自改用其他服务商或付费型号。
4. 可接入的服务及其数据去向，见《隐私政策》第二条第4项。
5. 如日后开放平台提供的模型额度，额度规则以届时页面说明为准，并适用本协议第七条。

你不得利用本服务从事以下行为：

1. 制作、复制、发布、传播法律法规禁止的信息，包括危害国家安全、煽动颠覆国家政权、破坏民族团结、宣扬恐怖主义或极端主义、暴力、淫秽色情和虚假有害信息等；
2. 侵犯他人的肖像、名誉、隐私、个人信息或知识产权等合法权益，或上传你无权使用的资料；
3. **将本服务用于考试作弊、代考或代写，或把 AI 生成的内容冒充本人原创，提交给考试或评审机构；**
4. 攻击、干扰本服务，绕过身份验证、授权或次数、费用限制，或批量注册、自动化抓取；
5. 使用他人的 API 密钥或未经授权的接口地址；
6. 转售、出租本服务，或用本服务向他人提供有偿服务；
7. 删除、篡改或隐匿本服务给 AI 生成内容加的标识。**你对外发布或传播 AI 生成的内容时，应按规定主动声明，并保留标识；**
8. 其他违反法律法规、公序良俗或本协议的行为。

发现违法内容时，我们将依法停止生成和传输，予以消除，保存记录，并向主管部门报告。你可以通过第十二条的联系方式投诉、举报。

## 五、AI 生成内容与学习结果 {#ai-content}

1. **AI 生成的讲解、题目、批改和建议由模型自动生成，可能不准确、不完整，或与最新考试要求不一致。** 本服务会在界面中标识 AI 生成内容。
2. AI 内容用于辅助学习，**不能替代教师指导，不代表官方答案、官方评分或考试结果。** 写作评估标注为「AI 评估」，训练档位不是考试分数。
3. 我们不对考试成绩、提分幅度或录取结果作任何承诺。重要内容请对照官方考试大纲、真题和可靠资料核对。
4. 发现 AI 内容有错误或不当之处，你可以在对话中纠正，也可以联系我们反馈。
