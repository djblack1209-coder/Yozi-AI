Yozi AI（以下简称「Yozi」或「我们」）是面向学生的 AI 学习教练，包括桌面 App、手机 App 和官网 yozi.bot.cd。运营方信息见第十条。

本政策说明我们提供这些服务时如何处理你的个人信息。你选择的模型服务商，按它自己的隐私政策处理你发给它的内容，不适用本政策。

我们依据《个人信息保护法》《网络安全法》《数据安全法》《未成年人保护法》《未成年人网络保护条例》《儿童个人信息网络保护规定》《生成式人工智能服务管理暂行办法》《人工智能生成合成内容标识办法》等法律法规处理个人信息，只处理实现你所选功能需要的最少信息。

加粗内容与你的权益关系较大，请留意。不满14周岁的用户，请由监护人阅读并同意本政策后再使用。

## 一、我们处理的个人信息及用途 {#collect}

1. **注册与登录**（必需）
   - 邮箱登录：处理你的邮箱地址、邮件验证码、你设置的密码和登录状态。密码经加盐、不可逆的方式处理后保存，我们无法知道明文。
   - 微信登录：处理微信经你授权提供的账号标识，以及你同意提供的昵称和头像。
   - 手机号登录：短信服务开通前不可用；开通后处理你的手机号和短信验证码。
   - 发送验证码时，我们记录发送时间和经可信代理确认的网络地址（IP），用于防止验证码被滥发。
   - 用途：创建账户、核验身份、保持登录、在多台设备上识别同一账户。
2. **建档与学习**（使用学习功能时必需）
   - 处理的信息：你在对话中告诉我们的学习目标、考试类别、考试日期、每日可用时长；你的作答、作文原稿与改写稿、错题、复习安排与结果、句式与搭配库、小结和对话记录。
   - 用途：安排每日训练与复习，显示薄弱点和进度，回看历史。
   - 这些记录默认保存在你的设备上。
3. **云同步**（可选）
   - 你明确开启同步后，学习记录会上传到我们的服务器，供你在其他设备上使用。
   - **服务器上的同步副本经压缩保存，不是端到端加密，有权限的管理员在技术上可以读取。我们通过权限控制限制访问。**
   - 官网开放登录后，只读取本人已同步的记录，不修改学习记录。
   - 不开启同步，也可以在本设备上正常学习。
4. **你上传的资料**（可选）
   - 处理的信息：你主动选择的文件（如 PDF、图片），以及从中提取的文字、页图和题目。
   - 资料默认在本设备内解析（版面整理、文字识别）。只有在你每次明确确认后，相关页图或片段才会随当前任务发给你选择的模型服务（见第二条）。
   - **整页图片可能含有其他题目、手写内容或批注。我们不会自动裁剪页图，也不会去除图片元数据。请在发送前确认，必要时先选取较小的区域。**
   - 你的资料不会进入公共题库，也不会被公开。
5. **AI 连接**（使用 AI 功能时必需）
   - 处理的信息：你选择的模型服务商、接口地址、型号，以及你提供的 API 密钥。密钥如何保存，见第二条第3项。
   - 用途：按你的指令调用该服务；从该服务实时读取可用型号；你重新打开 App 或用同一账户登录时恢复连接。
   - 检查连接是否可用、读取型号时，不发送你的学习内容。
6. **计算核对**（可选，目前关闭）
   - 开放后，你在某道题上明确请求计算帮助时，当前题目和你的作答会发到我们的服务器，由服务器上的计算程序给出参考结果。
   - 这一过程不调用模型，不发给第三方。结果只作参考，不改变你的作答和判分。
7. **用量与费用记录**（使用 AI 功能时必需）
   - 处理的信息：每次调用的服务商、实际型号、时间、输入输出用量、费用状态和执行结果状态。不记录你的学习原文。
   - 用途：给每次调用设定次数、时长和费用上限，防止重复扣费和循环调用，并供你和我们核对用量。
8. **模型结果恢复缓存**（使用 AI 功能时必需）
   - 处理的信息：模型返回的教学结果正文，与对应的调用关联保存。
   - 用途：网络中断后，让你取回已经完成的结果，不必重新调用、重复付费。保存期限见第四条。
9. **安全与运行**（必需）
   - 处理的信息：网络地址（IP）、请求时间、错误信息等网络日志。
   - 用途：限制滥用和暴力登录，防止验证码被刷，排查故障。
   - 登录限流使用经过不可逆处理的网络地址。

我们不收集你的通讯录、短信、通话记录、精确位置或广告标识符。App 没有内置第三方统计、广告或崩溃上报工具。手机 App 上架时，我们会在本政策中列出它申请的系统权限及用途。

如果要把你的信息用于本政策没有写明的目的，我们会事先单独征得你的同意。

## 二、AI 功能与模型服务商 {#ai}

1. **自行接入模型服务（默认方式）**
   - Yozi 的 AI 讲解、出题、批改和建议，默认使用你自己在模型服务商处开通的账户和 API 密钥。
   - 调用费用由服务商向你的账户收取，Yozi 不经手。
2. **发送给模型服务商的内容**
   - 发送条件：你选好一个已通过检查的连接，并在 App 中同意「允许发送学习内容」，即你对向该服务商提供信息的单独同意。在此之前，我们不会发送任何学习内容。
   - 每次只发送完成当前任务所需的内容：固定的教学说明、学习档案的精简摘要、当前题目或稿件、当天最近最多六条对话。历史原文不会整体重发。
   - 一项任务需要分几步分析时，每一步都使用同一个连接，在同一同意范围内发送。
   - 「灵感」建议只发送摘要：目标、考试、截止日期、每日时长、今日状态、前5个薄弱点、前8条句式等，不含原稿或反馈全文。你可以在设置中关闭。
   - 资料页图在每次单独确认后才发送。
   - 我们不发送你的登录密码，也不发送邮箱等账户身份信息。
   - 发送路径：你的设备 → Yozi 服务器（做安全检查和次数、费用限制）→ 你选择的服务商。
   - **内容一旦发给服务商，就由该服务商按其隐私政策处理，我们无法替你撤回。** 使用前请阅读所选服务商的隐私政策，并了解它是否把接口数据用于训练模型。
3. **API 密钥的保存**
   - **你的 API 密钥经 AES-GCM 加密后，单独保存在 Yozi 服务器的密钥库中，并与你的账户绑定。这样你重新打开 App，或在其他设备登录同一账户时，可以直接恢复连接。**
   - **这不是端到端加密：持有服务器部署主密钥的运维人员，在技术上可以解密。我们通过权限控制限制访问，密钥只用于按你的指令调用对应的服务商。**
   - 密钥不会出现在日志、普通学习导出或公开安装包中，也不会提供给第三方。
   - 你可以随时在「AI 连接器」中删除连接，对应的密钥记录会一并删除。运营备份中的副本按第四条的期限过期。
   - 建议你在服务商处为 Yozi 单独创建一个密钥并设好额度，不再使用时到服务商处作废它。
4. **可接入的服务**
   - 连接前，App 会显示你选择的服务商名称和接口地址。你的内容只发往你选择的服务。
   - **当前版本的 AI 连接器除国内服务商外，还列有部分境外服务商，并允许填写自定义接口地址。你选择境外服务商或境外地址时，发送的学习内容会传输到境外，由该服务商处理。** 我们正在把可接入的服务收窄为已依法备案的国内模型服务。
   - 如你连接在自己电脑或局域网中运行的模型服务，内容由 App 经本机连接器直接发往你指定的服务，不经过 Yozi 服务器。这类服务可能再把内容转发给其他云端服务，请自行核对。
   - 各服务商的名称、联系方式和隐私政策，以其官网公布的为准。
5. **平台提供的模型额度**（目前关闭）
   - 如果日后开放由 Yozi 提供的模型额度，你的任务内容将发给 Yozi 选定的已备案服务商，费用由 Yozi 承担并计入你的额度。
   - 开放前，我们会更新本政策并公布服务商名单。
6. **AI 生成内容的标识**
   - 界面会给 AI 生成的讲解、批改与建议加上「AI 评估」「AI 建议」等标识。
   - AI 对写作的评估是学习参考，不是官方评分。
   - 我们不使用你的学习内容训练模型。

## 三、本地存储 {#local}

- App 在你的设备上保存学习记录、草稿和恢复副本，用于离线查看和异常后恢复。这些数据存放在设备的普通存储中，我们不额外承诺系统级加密，请保管好你的设备。
- 搜索学习记录只在本机进行，搜索词不会发给模型或第三方。
- 学习图片在本机生成，默认不含身份、原答和资料内容，是否分享由你决定。
- 退出登录后，本机仍按账户保留学习记录，其他账户读取不到；身份、模型连接和临时凭据会被清除。
- 官网只在你的浏览器中保存语言和动态效果偏好，不设置广告或跨站追踪 Cookie。网络防护服务（见第四条）可能设置识别恶意流量所必需的安全 Cookie。

## 四、存储地点与保存期限 {#storage}

1. **存储地点**
   - 我们的服务器和数据库由云服务商提供，目前为腾讯云和 Sealos，位于中华人民共和国境内。
   - **访问官网和接口的网络流量经 Cloudflare 的网络加速与防护服务转发。Cloudflare 的节点可能位于境外，流量会在其节点上解密后再加密转发。**
   - 除上述网络转发和你自行选择的境外模型服务（见第二条第4项）外，我们不向境外提供你的个人信息。
2. **保存期限**

   | 信息 | 保存期限 |
   | --- | --- |
   | 账户信息 | 账户存续期间；注销后按第七条第5项处理 |
   | 设备上的学习记录 | 保存在你的设备上，直到你删除、清除本机数据或卸载 App |
   | 云同步的学习记录 | 直到你删除云端副本或注销账户 |
   | 上传的资料及提取内容 | 直到你删除该资料 |
   | AI 连接与密钥 | 直到你删除连接或注销账户 |
   | 模型结果恢复缓存 | 默认24小时，最长7天，到期后不能再取回。账户长期未使用时，过期内容在下次访问时清除 |
   | 用量与费用记录 | 账户存续期间，注销时随账户删除；法律法规另有要求的从其规定 |
   | 服务器访问日志（网络地址、请求时间等） | 不超过15天，到期删除 |
   | 验证码记录（含发送时间和网络地址） | 不超过24小时，到期自动删除 |
   | 安全审计日志 | 经脱敏后保留90天 |
   | 运营备份 | 备份周期确定后在本页公布，到期覆盖 |

3. 超过期限后，我们删除或匿名化处理你的信息。
4. 如运营方停止运营，我们会提前30日通过公告和 App 内通知告知你，并删除或匿名化你的个人信息。

## 五、我们如何保护你的信息 {#security}

- 数据传输使用 HTTPS 加密。密码不可逆处理后保存，API 密钥加密后单独存放。
- 每个账户的数据相互隔离，访问须经身份验证和授权。
- 我们会校验接口地址，拒绝访问内网等不安全的目标；每次 AI 调用都有次数、时长和费用上限。
- 我们限定可以接触个人信息的人员范围，并要求其履行保密义务。
- 发生个人信息安全事件时，我们会依法及时告知你：事件情况、可能的影响、已采取的措施，以及你可以采取的防范措施。我们也会按规定向主管部门报告。
- 互联网环境不是绝对安全的。请妥善保管账户密码和 API 密钥，不要与他人共用。

## 六、共享、委托处理、转让与公开披露 {#sharing}

1. 我们不出售你的个人信息。
2. 我们只在以下情形向第三方提供你的个人信息：
   - 按你的指令，把第二条所述内容发给你选择的模型服务商；
   - 取得你的单独同意；
   - 法律法规要求，或有权机关依法要求。
3. **委托处理**
   - 受托方及其工作：腾讯云和 Sealos 提供服务器与数据库；Cloudflare 提供网络加速与防护；邮件发送服务商为你发送验证码邮件。
   - 我们会与受托方约定处理目的、期限、方式和保护措施，并监督其处理活动。
4. **转让**
   - 因合并、分立、解散、被宣告破产等原因需要转移个人信息时，我们会告知你接收方的名称和联系方式，并要求接收方继续履行本政策。
   - 接收方改变原定处理目的或方式的，应重新取得你的同意。
5. **公开披露**：除法律法规要求外，我们不公开披露你的个人信息。
6. **依法无需你同意的情形**：
   - 为订立、履行你作为一方当事人的合同所必需；
   - 为履行法定职责或法定义务所必需；
   - 为应对突发公共卫生事件，或在紧急情况下保护自然人的生命健康和财产安全所必需；
   - 在合理范围内处理你自行公开或其他已合法公开的个人信息；
   - 法律、行政法规规定的其他情形。

## 七、你的权利 {#rights}

你可以在 App 内，或通过第十条的联系方式行使以下权利：

1. **查阅、复制与导出**：在 App 中查看学习记录，并导出个人学习数据。导出内容不含 API 密钥。
2. **更正与补充**：在 App 中修改学习档案和目标。发现其他信息有误，可以联系我们更正。
3. **删除**
   - 删除单份资料：同时删除由它产生的页图、题目、对话、作答与复习记录。
   - 删除云端副本：删除服务器上的学习记录，并清除你在服务器上的模型结果恢复缓存，本机记录保留。删除未全部完成时，App 会显示未完成，你可以重试。**如果其他设备仍开着同步，可能会重新上传本机副本，请先停止其他设备的同步。**
   - 清除本机数据：清除本设备上所有账户的学习记录、草稿和资料，清除后不可恢复。
   - 删除 AI 连接：同时删除对应的密钥记录。
   - **不在上述删除范围内的：你已导出的文件、其他设备上的本地副本、已发给模型服务商的内容、尚未到期的运营备份。前三项需要你自行处理或联系相应服务商，运营备份按第四条到期覆盖。**
4. **撤回同意**：在设置中关闭云同步、关闭「允许发送学习内容」或关闭灵感建议。撤回不影响撤回前基于你的同意已经进行的处理。
5. **注销账户**
   - 在 App 设置中申请注销。**申请后有7天冷静期，期间可以撤销。冷静期满后，我们删除你的账户、云端学习记录、资料、AI 连接与密钥、用量记录和恢复缓存，或作匿名化处理。**
   - 安全审计日志经脱敏后按第四条第2项的期限保留，到期删除。
6. **其他权利**：你可以要求我们解释处理规则，也可以拒绝或限制某项处理。
7. **答复时限与投诉**
   - 我们核验你的身份后，在15个工作日内答复。合理的请求原则上不收费。
   - 如果你认为我们的处理侵害了你的合法权益，可以向网信、教育等主管部门投诉，或向有管辖权的人民法院起诉。
8. **近亲属的权利**：用户去世后，其近亲属可以依《个人信息保护法》第四十九条，对其个人信息行使查阅、复制、更正、删除等权利，但用户生前另有安排的除外。

## 八、未成年人保护 {#minors}

1. Yozi 面向学生，用户中可能包括未成年人。
2. **不满14周岁的儿童，须由监护人阅读并同意本政策后，在监护人陪同下使用。** 我们将不满14周岁儿童的个人信息作为敏感个人信息处理。
3. 已满14周岁、未满18周岁的未成年人，请在监护人指导下阅读本政策并使用本服务。
4. 我们只为提供学习服务而处理未成年人的个人信息，不向其推送广告，也不提供与学习无关的内容。
5. 监护人可以通过第十条联系我们，查阅、更正、删除被监护人的个人信息，或注销其账户。如果发现在未经监护人同意的情况下收集了儿童的个人信息，我们会尽快删除。
