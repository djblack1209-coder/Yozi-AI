# Yozi 官网 v3 · 主题与方法笔记

Yozi 官网 v3 是按中文简报制作的本机候选。此页保留当时的设计与验证记录。

## 开工判断

**主题：一条作答记录在知识图上有位置，下一次练习从这个位置出发。**

学生能看到各科正确率，仍可能不知道明天练什么。同一个错误属于哪科、哪个分支、哪个知识点，决定了下一次练习的内容。官网把这段推理摊开，访客可以换科，检查建议的来由。

- **先给全图。** 标题问「下一题，为什么练这里？」。跨科分支占首屏大半幅面，学科、分支、薄弱点共享一条朱红线。换科时，全图的其他枝条留作参照。
- **再给凭据。** 规划、练习、复习共用一个带圈的节点。先从岔路选定它，再看到原答和订正，最后由回箭头回到同一个点。折线路径、笔迹和回路在静止时也成立。
- **最后给进入学习的条件。** 只在下载处说明自带 API Key、自选模型及各端可用性。纸色、墨绿细线、衬线大字与朱批来自翻看并订正一页习题的阅读习惯。入场只描出已有的证据路径。山湖的明暗无法解释题目选择，本次留作原资产。

- **画面判断。** 全文隐藏后仍能顺着分叉、笔下的订正、返回同一圈记的回箭头阅读。开发侧依实屏判断可辨。[无文案流程](../output/playwright/website-v3/no-copy-path.png) · [带例题的流程](../output/playwright/website-v3/zh-path.png)
- **换标实测。** 在浏览器内双向交换字标和主素材。Yozi 切至物理后读数变为「平均速率」，被换入的棱镜仍显示光路；Lazy 的「入射白光」标线落到了知识树上。Lazy 会话也独立切换了 Yozi 的三科，读回斜率、时间介词、平均速率。[Yozi 换图](../output/playwright/website-v3/swap-yozi.png) · [Lazy 换图](../output/playwright/website-v3/swap-lazy.png)
- **实操结果。** 三科按 111 次示例作答计数。数学 27/37，英语 30/37，物理 28/37；各科优先回练的节点在示例中均为 2/5。两种语言和两种尺寸均查过切科、焦点联动、语言记忆、404 与返回、原装 ZIP 实际下载；375px 和 390px 无横向溢出，右上控件成对同宽同高，高 44px。减少动效、禁用脚本终态、禁用存储、离线页面键盘切科均通过。首页脚本及资源错误为零。[浏览器回执](../output/playwright/website-v3/verification.json)
